# 霍乱时期的爱情 · 人物图谱

为 Albert King 制作。十三位人物，支持搜索、关系跳转、类别和时间阶段筛选及移动端阅读。

## 发布设置
Settings → Pages → Deploy from a branch → main → / (root) → Save。

网站：https://albertking206.github.io/cholera-character-atlas/

## 分享图片
Open Graph、Twitter Card、方形分享图和 Apple Touch Icon 均已配置。封面直接裁切自南海版书封插画，无添加文字，已避开书名区域。
来源：https://lib.ahnu.edu.cn/info/1009/2658.htm
书封版权归原权利人所有，用于书籍图谱辨识与分享。

参考此前百年孤独网站实测，可通过手机浏览器系统分享入口分享到朋友圈。各平台抓图及缓存不同，无法保证微信内分享一定显示封面。

index.html 内含原图谱数据、头像、样式和交互，无需构建。
