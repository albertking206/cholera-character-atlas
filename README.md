## 分享图片
Open Graph、Twitter Card、方形分享图和 Apple Touch Icon 均已配置。分享封面直接裁切自 Albert King 上传的书封，完整保留书名。横版 1000×525、方形 750×750，不缩放、不拉伸，PNG 无损保存。
当前封面来源：Albert King 上传的参考图。
